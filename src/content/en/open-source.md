Selected projects I have developed and maintain. There are more on [my GitHub profile](https://github.com/lassegit).

## rshono {#rshono}

### Minimalist web framework

A minimalist web framework built on Hono, Rspack and React Server Components, with an explicit API and no file-system routing conventions. This site runs on it.

## Sublime ES7 React/Redux snippets {#es7-snippets}

### Editor snippets

A popular snippet package for ES7, React, Redux and React Native in Sublime Text — both JavaScript and TypeScript.

## flask-reactjs {#flask-reactjs}

### Boilerplate

A Flask, React/Redux and webpack boilerplate, so a new project starts from a working setup rather than an empty directory.

## flask-scaffolding {#flask-scaffolding}

### Boilerplate

Flask scaffolding featuring SQLAlchemy, Backbone and Sass.

## react-collapse-simple {#react-collapse-simple}

### React package

A small library for collapsing and expanding content with a sliding animation, written in TypeScript.

## react-simple-social {#react-simple-social}

### React package

Every social share link through one simple, lightweight React component.

## git18n-node {#git18n-node}

### npm package

A lightweight npm package that abstracts translation management away from the developer.

## Browser lookup extensions {#browser-extensions}

### Chrome extensions

Quick dictionary and translation lookups straight from the browser — one extension each for DeepL, Langenscheidt and Ordnet.
