## rshono {#rshono}

### Minimalistisches Web-Framework

Ein minimalistisches Web-Framework auf Basis von Hono, Rspack und React Server Components, mit explizitem API und ohne Konventionen für Dateisystem-Routing. Diese Website läuft darauf.

## Sublime ES7 React/Redux Snippets {#es7-snippets}

### Editor-Snippets

Ein verbreitetes Snippet-Paket für ES7, React, Redux und React Native in Sublime Text — für JavaScript und TypeScript.

## flask-reactjs {#flask-reactjs}

### Boilerplate

Ein Boilerplate für Flask, React/Redux und webpack, damit ein neues Projekt mit einem funktionierenden Setup startet statt mit einem leeren Verzeichnis.

## flask-scaffolding {#flask-scaffolding}

### Boilerplate

Flask-Scaffolding mit SQLAlchemy, Backbone und Sass.

## react-collapse-simple {#react-collapse-simple}

### React-Paket

Eine kleine Bibliothek zum Ein- und Ausklappen von Inhalten mit gleitender Animation, in TypeScript geschrieben.

## react-simple-social {#react-simple-social}

### React-Paket

Alle Links zum Teilen in sozialen Netzwerken über eine einzige, leichtgewichtige React-Komponente.

## git18n-node {#git18n-node}

### npm-Paket

Ein leichtgewichtiges npm-Paket, das die Verwaltung von Übersetzungen von der Entwicklung fernhält.

## Browser-Erweiterungen zum Nachschlagen {#browser-extensions}

### Chrome-Erweiterungen

Schnelles Nachschlagen in Wörterbüchern und Übersetzungen direkt im Browser — je eine Erweiterung für DeepL, Langenscheidt und Ordnet.
